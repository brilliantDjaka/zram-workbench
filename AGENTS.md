# AGENTS.md

Project: **zram-workbench** — devbox-based zram compression benchmark harness (privileged apply script + measure-only bench script + sequencer).

## Journal

`JOURNAL.md` is a diary of completed work, one section per change/event, newest
first. When a change/event is completed, insert a new `## YYYY-MM-DD HH:MM -
Title` section directly under the header, above the previous newest section
(local 24h time). Body template:
- **What:** what was completed
- **Why:** why it was needed, if non-obvious
- **Changes:** free-form description of key changes and behavior
- **Tests / Verification:** how it was verified
Never append to an existing section, and never reorder or rewrite existing
entries. Keep entries detailed and factual; never credentials or secret values.
Commit the journal update with the task's changes.
